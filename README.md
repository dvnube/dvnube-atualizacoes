# Atualizações DVNube

Este é o canal de demonstração do painel DVNube. No painel local, clique em **Verificar atualização** ao lado da Luna. O piloto 0.1.0-beta.1 oferece a versão 0.1.0-beta.2, que exibe uma confirmação no rodapé.

O canal distribui o catálogo assinado e os dois arquivos de configuração da demonstração. O instalador do produto é entregue pela DVNube em separado.
